# Independent Linux GlobalAi wire review

No material codec defect was found in the reviewed current-version transport. This review accepts the bounded wire boundary only. Complete gameplay state, native Read reconstruction, gameplay RNG, actions and turns remain unimplemented or unaccepted by this review.

The immutable tested source is `69b5aea78cd0af35b4b89f9e2c069aed7d32ae81`, including its actual `pub mod game_global_ai` crate export. The review extracts one unchanged Git archive, tests the crate, builds it and links an external review harness against the exported crate. It neither injects an export nor recovers modules from later commits. All archived files are hashed before and after the build. [Machine-readable results](../evidence/linux/game-global-ai-review.json) record the archive, module, harness and executable identities.

The review gates Linux XP2 SHA-256 `a0b6611f45ed28fa7bf6e18d608cafddbdd5b1c20cfd880cb50937af731c1faa` and Linux host SHA-256 `106d4986567cf60aad787dfac990d089e41775e04b5f40e073f59a3a8ffe74f4`; host ET_EXEC addresses are absolute. No original code is executed. The existing audit's complete function-byte identity list is reused only after checking its driver against the immutable source commit. Original ELF disassembly independently confirms GlobalAi v4 writer `0x20f41d0`, reader `0x20f42d0`, and parent Player.Manager → GlobalAi → Barbarian.Manager call ordering. The parent GlobalAi writer and reader sites `0x2d7a879`/`0x2d7ab9a` resolve through their PLTs to `0x20f41b0`/`0x20f42b0`.

Current grammar review confirms the wrapped u32, Mayhem float bits, Control.Factory, AI::EspionageManager, AI::ReligiousManager, Q8 word, i32 vector and two Yield-hash/Q8 arrays. Nested versions match the current writer: Mayhem/Factory/Handle/BeliefAnalysis v1, EspionageManager v1, Espionage v4, EspionageCityAnalysis v3, ReligiousManager v2, Religious v6, and CityReligionAnalysis v4. In particular, the espionage act array has eleven current entries, Religious body presence depends on the nonzero raw bool byte, and CityReligionAnalysis emits Q8 offsets `0x18`, `0x24`, `0x1c` in that order. CityID is two signed i16 fields plus u32 ID; PlotCoord is two signed i32 fields. These concrete nested carriers are defined locally; the unrelated Player.Espionage codec is not reused.

The [independent review driver](../evidence/linux/game-global-ai-review.py) implements a separate Python parser and a separate Rust traversal of every decoded public field. Both produce an ordered projection of signed/unsigned scalar values and vector lengths, retaining float bits, raw bool carriers, ordinals, unknown/duplicate hashes and signed Q8 words. It compares all 92,638 projected words per record, independently sums nested counted items, checks all 86 direct native child extents per record, and requires exact byte roundtrip. This catches field assignment/sign/order defects that byte roundtrip alone can miss.

Both SHA-gated canonical streams place the complete 368,461-byte record at `70566134..70934595`, following Player.Manager and preceding Barbarian.Manager. Both records are identical (`d70893e3576acd575d02df74e7ddae85901e9f98311d24a2719f06c7744ed05b`) and contain 47,501 counted items, 43 Espionage records and 43 initialized Religious records. They are two original stream contexts with one distinct GlobalAi payload; they do not establish broader gameplay diversity. Native trace offsets are comparison inputs only, never production parser inputs.

Validation covers every parsed scalar/group transfer start, first interior byte and last byte as a truncation, plus every structural version/count site mutated to zero and u32::MAX when the mutation changes the original word. Each record passes 205,632 distinct truncation cuts and mutations at 13,303 structural sites. It also checks exact and one-short byte/item limits on decode and encode, aggregate nesting, strict trailing rejection and exact prefix consumption with a suffix. Source inspection confirms checked count multiplication/addition, input/minimum-wire and aggregate-item checks before fallible reservation. The checked allocation ledger is overflow accounting, not a separate heap-byte limit; `Limits.max_bytes` caps consumed wire bytes and `Limits.max_items` caps aggregate counted entries. Source-only crate tests cover all 256 raw bool carriers, absent Religious bodies, every small-fixture byte cut, float edge/NaN bits, signed extremes, duplicate hashes, fixed-array count rejection and inconsistent present-body flags. The three source tests and strict Core Clippy run from the same unchanged archive.

Native Read additionally initializes analyzers, resolves players and definitions, resizes vectors, initializes signals and archives, and handles historical versions. This transport deliberately rejects historical wire versions and does not reproduce those live effects. No AI-namespaced field is discarded or classified as planning-only. Every future player decision must remain an external-policy boundary. The raw Save→Load discrepancy remains **89,198 bytes**, unmasked and unclassified. Full world import, initialized native reconstruction, gameplay state/RNG, actions and turns require further evidence and implementation.

Reproduce with `python3 evidence/linux/game-global-ai-review.py` from the repository, with the authorized sibling Linux assets and private canonical evidence available. The driver writes only its public JSON report and temporary build files.
