# Bounded CityAttributes default source review

Source packet `54e5ca4` plus tightening `d0153d5` is accepted for a **positive-size, fresh canonical single-Map read/restore lifetime with checked `2*P <= 65535`**. Under the packet's normal typed ownership and Reflection output contract, reserved primary node0 retains raw signed mask0 and packed Wonder-1; the latter makes Wonder completion false before City lookup. These values come from original stores and control flow, not the native-2 observed zero/false answers. [Independent evidence](../evidence/linux/city-attribute-default-review.json) records the checks and limits. This approves a bounded source-derived default model; it does not add that model or promote the frozen candidate's unavailable outputs to parity.

The final static audit reproduced exactly: 62 base complete methods, 81 extended writer/copy method hashes, 92 narrow store sites and 13 references to the entire primary sparse pool. An independent complete-target Intel scan reproduced all 92 sites and 68 containing-method hashes. Six of nine WORD stores belong to the known CityAttributes initialization/read/mutable paths. The other three receivers were independently traced to newly allocated BuildingProductionData, Combat Member and newly allocated PetTheDog command objects. Their gameplay relevance remains in scope; their receiver identity excludes them from this primary default proof. Primary pool `0x3c05df0`, Cache pool `0x3c02de0` and the unrelated global empty attributes object `0x3c05d68` remain distinct. Original primary lookup falls back to sparse node0.

Independent sequencing inspection confirms that Map.Read reads the incoming saved dimensions before Initialize/Reset. Reset uninitializes an old nonempty map before assigning new dimensions. InitPlots initializes canonical coordinates and clears/reserves primary node0 before component and Map-initialized callbacks. The Game stream reader invokes one concrete Map wrapper/Read, then later yield/domain restoration and XP2 augmentation. The typed vector-length condition prevents another Plot resize after initialization. Thus prior-map size does not supply the pre-read population bound.

Pre-read callbacks may already allocate one current node per canonical plot. Each saved Plot.Read resets its local index without freeing that prior node, and can allocate one replacement. Those orphaned nodes must be counted. At most P orphaned nodes and P current owned nodes coexist, plus reserved0. Free nodes are reused before append, so constructed vector length stays at most `2*P+1` and returned allocation index at most `2*P`. Geometric storage capacity can be larger. For P=6,996 the bounds are 13,993 constructed nodes and maximum index13,992. An independent source-only allocator abstraction explored 9, 106 and 1,735 reachable states for P=1,2,3, including edits, frees, absent/owned reads and every free-node reuse choice. It retained the bound; this is not an original-code oracle.

Five explicit primary local-index writes and the Plot copy/assignment paths were inspected. Copies preserve the index within the word at+0x48 and occur in vector helpers; fill temporaries are not extra edited canonical owners. No additional primary reset receiver was found in the indirect+0x80 scan. That scan includes stack-held function pointers; register mentions and namespace names were not used as a substitute for receiver tracing.

Bulk payload directions were checked separately from narrow stores. All three CityAttributes copy-constructor destinations are stack objects. Sparse-node relocation moves each corresponding payload, preserving entry0. Both Reflection Fill functions read 24 bytes from const attributes and write the output DTO; the export wrapper only forwards that output pointer. The sole direct internal primary Fill caller writes a stack DTO at RSP+0x38, then builds a separate event node. All three Update destinations are cache mutable attributes. The exported FillCache virtual slot is+0x190; the target has no internal indirect call/jump using that offset. External Reflection outputs must obey their normal typed, nonaliasing DTO contract; this is not an arbitrary external-pointer safety theorem.

The proof remains scoped. The global+0x38 scan contains 2,992 heterogeneous sites, and this review does not claim a complete taint analysis of every receiver or arbitrary wider/adjusted store. Acceptance relies on the evidenced typed mutation/copy interfaces and canonical ownership contract. Raw narrow-store completeness alone is not universal nonmutation proof. Arbitrary imported allocator history, extra out-of-band reads/resets, mutable Plot clones or private-pool output aliasing do not satisfy this boundary.

Two conditions were clarified during review. **P>0 is required**: an empty Plot vector skips CityPlots.Initialize/reservation, and the Map wire codec alone permits zero dimensions; the existing MapDomainInputs geometry gate excludes them. The bound concerns constructed nodes and returned indexes rather than raw reserved capacity. A prospective model must enforce these conditions explicitly and fail outside its supported phase/bound.

The original overflow counterexample remains: allocation result65,536 narrows to u16 zero, and EditAttributes(0) can return the reserved node for mutation. The maximal source-only P=32,768 orphan/read path reaches that result, while P=32,767 remains inside the conservative bound. Larger maps and arbitrary-history overflow/alias behavior remain required for the full engine; they are not silently defaulted or permanently excluded.

No original code executed for this review. No new default model or all-plot native comparison is claimed here; the earlier `e899e4d9…` artifact remains immutable. A new candidate can compare independently derived defaults with the retained 1,709 native-2 fallback rows while preserving the capture's original profile and candidate binding. Complete gameplay state/RNG, externally supplied decisions, actions and turns remain unfinished. The raw **89,198-byte Save→Load difference remains unresolved and unmasked**.
