# Linux Player.Governors saved wire

The codec covers the current serialized Player.Governors component and its complete transitive Governor records. It does not implement governor decisions, gameplay, a complete Player/world import, native object restoration, actions or turns. The separate later AI::Governors component is not this record and has not been excluded from gameplay state by its namespace. The recorded raw Save→Load difference remains 89,198 bytes, unmasked.

The pinned Linux GameCore SHA-256 is `a0b6611f45ed28fa7bf6e18d608cafddbdd5b1c20cfd880cb50937af731c1faa`; host SHA-256 is `106d4986567cf60aad787dfac990d089e41775e04b5f40e073f59a3a8ffe74f4`. Static Linux instructions and DWARF are authoritative here; reference revision `5af389445118bed2bdebf7a8a42b219c8fba5175` is discovery only. The audit never executes original game code or writes private artifacts.

Player call `0x2b4f191`, PLT `0x1f9ed50`, resolves to writer `0x2b09260`; reader is `0x2b092e0`. The writer emits local version 6 (`0x2f61330`), signed governor points, recycled governor list, signed neutralized-indefinitely, title-considered bool, favored Governor definition hash and signed diplomatic favor. Starting-governor count, maximum titles and the parent pointer are not written by this serializer.

The recycled container writer/reader `0x2b0cd30`/`0x2b0cf40` emit version 65537, ID width 16, capacity, unsigned active count, repeated signed slot index plus Governor, current ID bits, unsigned free count, head, tail, and the ordered unsigned free-link sequence. Capacity and all ID metadata remain explicit; no native capacity allocation is requested by this codec.

Governor writer/reader `0x2a36430`/`0x2a36660` use local version 16 (`0x2f551cc`). They serialize governor identity, definition hash, encoding-0 name bytes, assigned CityID, owning PlayerTypes ordinal, six signed pressure/site words, established bool, seven signed neutralization/identity/alliance/modifier words, assign-to-major bool, three signed resource/faith/heal words, established-city map, promotion hash/bool array, city-state bool and grievance vector. Field names follow Linux DWARF. These signed values are ordinary native integers, not inferred Q8 values. CityID is signed 16-bit owner, signed 16-bit component type and unsigned 32-bit ID. Grievance writer/reader `0x2a36ab0`/`0x2a36af0` write local version 1 and signed score/turns. Promotion arrays preserve hashes and canonical bools; maps/sequences preserve order and duplicates. Strings preserve arbitrary bytes without localization or Unicode normalization. Established-city counts are written unsigned but consumed as signed by native Read; negative counts are explicitly unsupported.

Native Read is separate: the recycled reader may destroy/reserve, AddAt and reconstruct free links. Instance Read remaps definition hashes, inserts city-map entries and updates promotion storage. The wire codec does not perform those operations, callbacks, RNG changes, reset or initialization. Current Player.Governors Read itself calls serialization/version wrappers, not Initialize/Reset.

`Governors::{decode,decode_prefix,decode_prefix_with_items,encode,encode_with_items}` use `unit::Limits`. One item means one dynamic sequence/map entry or string byte, aggregated across every nested container. Decode first scans the complete grammar without allocation, checking wire bounds, aggregate item limits and checked aggregate typed storage at most `isize::MAX`; only then does it use fallible typed reservations. Encode measures its complete wire/items/storage before allocating output. Typed storage is governed by the item policy and checked addressable extent, not equated with serialized byte count. Canonical bools, exact current versions and recycled metadata are checked.

Run the committed audit with `python3 tools/linux/player_governors_audit.py --source-commit COMMIT --output /tmp/governors.json`. It builds one isolated archive containing both module and driver, runs actual Cargo Clippy and unit tests, gates native identities and instruction/PLT/DWARF contracts, and compares full original records in both canonical saved streams. There are no direct Governors owner hooks: source-closed WMD and Improvements grammars locate the prefix from Quests.end, bounded contextually by enclosing Player.end. That is a structural location limit, not a fabricated native cut. Evidence records actual corpus occupancy; source carriers exercise nonempty Governor nested fields even where native records are empty.

The successful candidate is archived commit `c2a8d54aa2c0092a82ea3d776a933dcbbab0ce53`; [evidence](../evidence/linux/player-governors.json) records source, archive, executable and harness hashes. Both canonical streams roundtrip all 43 structurally located records each: 45,413 bytes and 8,839 aggregate items per stream, including nonempty Governor instances. Exact native caps pass; one-short caps and every proper prefix fail. Actual Cargo Clippy and the three Cargo unit tests pass in the archived workspace. Native original-code execution and a gameplay-state oracle remain unavailable in this audit.
