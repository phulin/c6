# Independent Manager world adapter review

Implementation `7e6421d` and audit/documentation `94e81a1` pass review for their bounded source-derived metadata adapters. The [review evidence](../evidence/linux/unit-operation-manager-world-review.json) pins those files, the complete extracted source archive and both Rust executables. The [independent driver](../tools/linux/unit_operation_manager_world_review.py) verifies the archive, independently reconstructs outputs, checks selected complete original methods and declared widths, and runs eight additional Rust boundary groups. No original code was executed. This extends the earlier Manager control-flow contract; it does not establish full Manager, action, state/RNG or turn parity. The separate native metadata helper remains unadmitted by this review.

Original Read invokes Reset before consuming saved pairs. Reset writes its false default byte and initializes exactly the actual operation-definition count to false. Each saved pair then resolves through the actual definition collection; an unknown key still consumes its bool, and a later pair for an already resolved index overwrites the earlier value. The source reproduces those value semantics. It models neither native vector allocation/capacity nor all live IndexList mutations after Read. Queries use the definition collection borrowed by the restored vector, rather than a different registry or saved-pair count.

Complete Definition.Find/FindIndex and HashToIndex inspection confirms direct-index priority for unsigned keys below count, then actual hash lookup, then the definition's collection index. Duplicate hashes retain the established last-inserted precedence. Signed operation inputs keep their raw bits: `-1` can resolve when those bits identify a real definition, and is not blanket rejected. Runtime collection index, definition hash and SQLite rowid remain distinct. The genuine 63-entry original registry supplies ordered metadata; no expected disabled answers feed restoration.

The audit was rerun from a fresh isolated archive of `7e6421d`, independently verifying every extracted source file before building. The replay decodes **1,262 Units × 63 definitions**, consumes **79,506 saved pairs**, reconstructs zero true slots, and preserves each complete Unit's bytes. A second independent remapping agrees. This fixture exercises no unknown saved key and no resulting true value; every Unit also has 63 pairs, so this fixture alone cannot distinguish definition-sized initialization from pair-sized initialization. The synthetic tests provide the missing short/empty/unknown/duplicate/true cases. No independently observed live IndexList bytes were compared, and a fresh restoration cannot silently replace a vector mutated by later gameplay.

Phase selection filters by supplied configured type, sorts by signed PhaseOrder and rejects ties within the selected type. Ties outside that type do not matter.
