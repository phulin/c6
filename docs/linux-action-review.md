This is targeted interception. Because original pending processing can mutate before entering that guard, an aborted run is a preserved failing diagnostic, not a successful nonmutating rejection or resumable external-policy yield. Do not remove original passive rules, blanket-suppress AI namespaces or count native policy choices as external decisions.

None of these limits blocks the bounded exploratory probe; all constrain its acceptance claim.
