# Linux Map and Plot wire codec

`c6_core::map` decodes and encodes the complete supported current **Map v4 / Plot v6** wire section, including all six named map components. The Rust candidate matches every byte, all **2,208,846 independently decoded typed values** and **315 original nested serializer boundaries** in each supplied lifecycle stream. Both streams contain the same Map; they are not different gameplay or map-generation fixtures.

This is typed world-state transport. It does **not** perform native Map::Initialize/Read reconstruction, import a complete live world, implement movement, execute actions or advance turns. Gameplay `Engine::apply` remains unsupported. Unknown save bytes outside this section are neither classified nor masked, and the recorded raw Save→Load failure remains **89,198 bytes**.

The [original contract](linux-map-state.md) establishes field order, native types, current versions, omitted fields and lookup relationships against Linux XP2 SHA-256 `a0b6611f45ed28fa7bf6e18d608cafddbdd5b1c20cfd880cb50937af731c1faa`. The [codec evidence](../evidence/linux/map-codec.json) pins the candidate, source files, independent structural parser, original streams and owner traces. Discovery attribution and private evidence identities remain in the contract; no proprietary code, game payload or private project is committed here.

`Map::decode` retains native order in compact vectors. It includes the Map dimensions/wrapping/latitude/definition hash and saved counts; resource arrays; visibility layers and outgoing records; recycled Area, Landmass, Region, Chokepoint and FeatureLayout collections; Continents; every Plot field and nested typed property; sparse unit occupancy; and typed Route, Feature, River, Terrain, Territories and TerritoryBuilder payloads. There is no opaque component fallback. Current schemas also cover nonempty Route portals, Terrain lists and Territory records with recursively localized names. Their source-derived tests are deliberately separate from native coverage: the actual native fixture has zero entries in those branches.

Definition values remain actual serialized hashes, not runtime indexes, SQL rowids or invented references. Hash/value arrays preserve order and raw signed values. Native indexes must later resolve against the exact active Linux registry, rules database, DLC/mods and configuration. Plot Area/Landmass/Region IDs remain distinct from recycled slot indexes and generated-ID metadata. No generation, free-list or saved aggregate is normalized. In particular, saved owned-plot count zero is preserved despite 5,287 present CityAttributes. The serialized player byte and owning-city ID stay separate; no ID bit-slicing or ownership recount is introduced.

Flags retain all 17 named current bits. Spare bits, mismatching property counts, noncanonical scalar booleans, unsupported versions/names/variant branches, inconsistent supported dimensions and noncurrent localized forms reject explicitly. Restrictions are codec policy for the supported current writer profile, not claims about every malformed input accepted by native Read. Optional property absence represents the wire's zero count and does not assert a null native pointer. Raw string bytes, signed integer widths, float NaN/sign bits, fixed-point raw values and callback-independent ordering are preserved.

Localized Territory names support all six current argument tags: none, i32, Linux i64 long, raw f32, raw f64 and recursive text. The current prefix/format and one-name-per-named-argument writer form are supported. Legacy prefixes, other format bytes and multiple names in one record reject; the native reader's broader behavior is not silently normalized. No localization rendering or service/reference-count behavior is modeled.

`plot_by_index` and `plot_at` provide allocation-free O(1) lookup into the native x-inner/y-outer sequence; `coordinates` reverses that index. `plot_at` accepts canonical in-bounds coordinates only, including on a map whose wrap flag is set. It does not substitute ordinary modulo for native CoordRange: negative wrapped exact multiples have a documented native edge case. Movement, wrapped lookup and pathfinding remain separate work. `SparsePlotData::get` implements the verified default-selection branches and explicitly errors on an invalid value reference rather than inventing a default.

Caller `Limits` bound input/output bytes, aggregate dynamic items, logical model allocation and recursive depth before the relevant allocations. Known fixed minimum wire widths are checked against remaining bytes before reservation. Generic zero-minimum sparse-value vectors rely on aggregate resource budgets and per-element truncation checks. Typed-variant allocation uses a conservative per-item bound. `max_allocation` covers logical model vectors/boxes and those conservative charges. It is **not a process heap ceiling**: allocator rounding/bookkeeping, encoded output and temporary component buffers are not that counter. Output and temporary encoded lengths are separately constrained by `max_bytes`; their vector capacity is not a heap-ceiling guarantee. `decode_with_ranges` additionally charges its range records; ordinary decode avoids range collection. The library makes no hidden world copy per action; it implements no action path.

Reproduce offline:

```sh
python3 tools/linux/map_codec_audit.py --output target/linux/map-codec.json
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
bash tools/check/c_abi_smoke.sh
```

The audit selects the outer Map owner from each exact original trace and derives nested sections structurally. It uses no fixture section offsets in the library or extraction. The retained candidate is frozen by hash before comparisons, and sources are checked for changes during the build/check. Every typed value, all 6,996 Plot records, ten section ranges and 315 actually observed nested owner ranges are compared independently. The original trace does not contain component-internal MemoryOStream owner ranges; those are not counted as observed native boundaries. Full typed component values and exact framed payload bytes are compared instead.

Native coverage includes 43 visibility instances, 126 Areas, seven Landmasses, 131 Regions, 254 Chokepoints, six Continents, four FeatureLayouts, six property-bearing Plots, 5,287 CityAttributes, four unsorted unit layers, 23 Volcanoes, one natural-wonder Volcano and 22 Rivers. Nonempty Route portals, Terrain vectors, Territory/localized records, Ice and wrapped maps still need original-code fixtures. Seven source-contract test groups exercise those generalized forms where applicable, byte/flag/signed-width extremes, recursive raw floating-point arguments, truncations and resource limits. An independent hand-authored generalized carrier also roundtrips and matches every decoded value; it is explicitly a wire test, not an original-code fixture or gameplay-valid world.

Release timings measure real decode with allocation/validation/drop, encode with its buffers/drop, and coordinate/index lookups using precomputed keys. Diagnostic JSON, range collection, fixture preparation, native execution/I/O, initialization, definition/live-state reconstruction, movement, actions, turns and RNG are excluded. Codec agreement and these timings do not reduce or complete the full exact simulator objective.
