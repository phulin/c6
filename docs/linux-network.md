# Original Linux offline network ownership fixture

The explicit native network profile uses genuine `Civ6App::SetupNetwork()` on the already constructed and published original App. Its verified Linux signature is `bool(this)`, with no explicit boolean parameter. The original method creates the real Network Manager, initializes its real FireWire, synchronization and archive services, subscribes to actual App events and processes the genuine CRT main arguments. No session, player ID, callback or transport implementation is substituted.

The fixture accepts the diagnostic's actual one-argument process command line. The runner captures the original `argc` and `argv` from genuine glibc startup; the adapter binds them through the same AppEnvironment fields written by original `RunApp` at `0x42b9aa3` and `0x42b9aa7`. It refuses a different published App before any field mutation. The shared `c6_linux_register_host_events` helper calls genuine App event registration once per App lifecycle, so later mod-framework preparation preserves Network event subscriptions. Its guard resets when that App is destroyed.

Network initialization unconditionally creates the archive and FireWire singletons. The explicit profile therefore skips the independent archive fixture used by the existing standalone Context diagnostic. It refuses existing Network, Archive, FireWire or Sync owners before original SetupNetwork. A genuine MessageFactory already exists when the fixture reaches network setup: original FireWire construction explicitly reuses it at `0x3a017c5..0x3a017d7`. The fixture verifies that exact original pointer is preserved rather than overwritten.
