# Linux Player AI InfluenceMap saved wire

The bounded [Rust codec](../crates/c6-core/src/player_ai_influence_map.rs) preserves the current Linux XP2 `AI::InfluenceMap` saved wire: little-endian `u32(2)`, unsigned `u32` influence count, that many signed `i16` values, unsigned `u32` religious influence count, then signed `i16` values. Order and every value bit are retained. Unsupported versions fail explicitly. Prefix decoding consumes only this record, with cumulative wire byte and dynamic item limits; each vector's count, item budget and available wire extent are checked before fallible allocation. Encoding preflights both counts, cumulative items and exact wire size before allocation.

The [audit](../tools/linux/player_ai_influence_map_audit.py) gates the supplied original Linux module SHA-256 `a0b6611f45ed28fa7bf6e18d608cafddbdd5b1c20cfd880cb50937af731c1faa`, serializer bytes, direct PLT bindings and concrete wrapper vtable slots. Writer `0x2140e00` emits version 2 and wrapped vectors at `+0xb0` and `+0xd8`. Reader `0x2140e50` always loads the first and delegates the second to `ReadVersioned` (`0x2142900`), which reads it for historical versions >=2. Older versions are outside this codec. DWARF identifies both values as `Types::Vector<short>`; sequence helpers at `0x21448c0` and `0x2144b10` read/write unsigned 32-bit counts, and scalar helpers transfer exactly two bytes. Wrapped virtual load/save slots resolve to `0x2143e10` / `0x2143e80`, which delegate directly to vector serialization.

Player writer sites `0x2b4f23a`, `0x2b4f249`, `0x2b4f258` establish Control, InfluenceMap, Planning order. The two SHA-gated canonical original Save streams and their checkpoint-203 owner traces contain **no InfluenceMap owner hook**. The audit derives 86 comparison cuts from each Control end to the following Planning start, requires their shared Player parent, reconstructs both typed vectors, and checks exact extent against the independent Planning boundary. These offsets are evidence only; production parsing has no fixture offsets, search or owner trace inputs. Each stream contributes 43 records. The report records individual byte extents and identities.

Current InfluenceMap Read performs the two wrapped loads, without calling Initialize. However, the enclosing Player reader explicitly calls `InfluenceMap::Initialize` at `0x2b4f4ae`, before reading even the Player version. Initialize (`0x21410c0`) calls Uninitialize, establishes archive component identity `0x41`, stores the live Player pointer at `+0x98`, and subscribes to a Game Unit signal through the handle at `+0xa0`. Constructor `0x2140eb0` constructs archive/handle/wrapped vector members. The codec reconstructs none of those runtime relationships, allocation histories or service callbacks. Saving only the vectors does not prove the unsaved state unnecessary.

Both vectors remain required, semantically unclassified state. No planning-only exclusion, transitive RNG isolation, live state initialization, original Read oracle or gameplay equivalence is claimed. Complete Player/world state, external decision boundaries, actions and turns remain unsupported. Gameplay RNG remains in scope and the recorded **89,198-byte raw Save→Load difference** remains unmasked. Reference discovery attribution is the pinned [cru121 reference](reference.md), revision `5af389445118bed2bdebf7a8a42b219c8fba5175`; Linux target bytes and DWARF establish this contract.
