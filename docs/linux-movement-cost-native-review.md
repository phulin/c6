## Corrected caller provenance and ABI

The original MoveTo caller stores the initially requested destination at its baseline stack `+0x30`, while the current source is at `+0x40`. After its eight-byte stack adjustment, the full-cost call loads source RDX from `+0x48` and exception R8 from `+0x38`. Therefore the exception is the initially requested destination, not the source. The no-ZOC branch uses the same destination with its corresponding stack adjustment. The reviewed single-edge helper now passes the actual adjacent destination consistently to IsSlowedByZOC, full cost, no-ZOC and the Values overload. Options zero is an explicitly recorded query argument; it is not a reconstructed player command or a change to private flags.

Full cost returns nontrivial FixedPoint through output RDI, followed by formation RSI, source RDX, destination RCX, exception R8 and integer base R9D; maximum/remaining pointers and options are stack arguments. Values construction takes output RDI, formation RSI, source RDX, destination RCX, integer base R8D and maximum-Q8 pointer R9, followed by remaining/exit pointers and selector. GetFinalCost uses output RDI and Values RSI. These projections match the inspected wrappers. Aligned local outputs survive every call; the helper does not treat these methods as ordinary integer-return functions.

The native MoveTo source lookup itself uses Formation.GetLocation and Map.GetPlot(coordinate). GetLocationLayer queries the unit-container layer of an actual member, rather than selecting another Plot registry. The supporting original caller and Map virtual binding therefore justify the source lookup without inventing a layer-zero restriction.
