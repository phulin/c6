# Linux Player middle AI wire review

The five current saved-wire codecs pass focused review from unchanged actual-export archive `968ab50e37206e6c15d8a06bf20e3e6567b03644`. The [reproducer](../evidence/linux/player-ai-middle-review.py) and [evidence](../evidence/linux/player-ai-middle-review.json) accept bounded typed transport only. They do not accept native Read restoration, live AI decisions, full Player reconstruction or turns. No implementation mismatch was found.

The target is Linux `libGameCore_XP2.so` SHA-256 `a0b6611f45ed28fa7bf6e18d608cafddbdd5b1c20cfd880cb50937af731c1faa`. Discovery names follow the [attributed reference](reference.md), revision `5af389445118bed2bdebf7a8a42b219c8fba5175`; exact Linux bytes, symbols and DWARF govern the contract. No original code executes.

Neither GrandStrategic nor Homeland has an outer hook in these traces. Their joint grammar consumes exactly the interval between Governors.end and the same Player's Military entry; Military's following v14/player header is checked. Available nested Diplomatic, Governors, VictoryStrategy, PlotEvaluation and UnitEfficiencyInfo hook extents are compared individually with independently projected spans. No trace cut enters the production parsers. All actual Player v47 headers have WasEverAlive=true; parent false-branch framing is outside this component acceptance.

The archive's five codec modules are explicitly compared with their earlier closed tested source pins before validation. Every archived regular file is checked unchanged after the build. The candidate imports the actual public modules; it never injects exports or recovers source. All five focused Cargo test suites and strict all-target c6-core Clippy run from that archive. The review regates the complete target method contracts against hashes and exact ELF symbol sizes, exact DWARF contracts, existing explicit instruction/PLT bindings and relocated virtual slots. It additionally checks all 74 archive load/save virtual slots belonging to these root AI classes and records their complete method bodies. The combined manifests contain 649 distinct complete method extents. Direct instruction targets and resolved bodies are recorded separately from unresolved import bodies; an unresolved external implementation is not claimed as reviewed.

Independent Python field contracts and explicit Rust public-field projections compare **every typed scalar and container count directly**, including versions, signed halves, raw bool storage, string bytes and ordered hash rows. Byte-for-byte re-encoding is an additional check. Matching a digest or merely parsing a suffix does not substitute for the complete typed comparison.

The contracts retain several distinctions that matter for future live reconstruction:

- Diplomatic's state, transition and trigger names are counted raw byte strings. No UTF-8 conversion or termination requirement is added. TradeItem preserves its unsigned type/subtype/value words. State/handler vectors, nested visible-score rows and partner-action hash arrays retain saved ordering and duplicates. Handler v5 contains desirability and cost hash arrays **only when both saved player IDs differ from −1**. Per stream, 1,055 of 2,752 handlers contain both arrays and 1,697 omit both. Missing arrays are absent wire, not zero-count placeholders. All four missing/present player-identity combinations are additionally source-tested; typed optional payloads inconsistent with the IDs are rejected before encoding.
- Economic stores six signed raw Q8 income/balance/expense words followed by signed counters, savings vectors, ordered Yield-hash/Q8 entries, Control.Handle v1 and AI.Trade.Player v3. AI.Trade.Player's saved road is a Route hash, while its control ID remains a raw unsigned ID. This nested Trade record is distinct from Player.Trade v35. Economic has no bool byte.
- AI Governors is distinct from gameplay Player.Governors. GovernorAnalysis v4 has separately counted CityID and Q8 vectors; unequal lengths are legal wire carriers. CityID is exactly signed i16 owner, signed i16 component type, unsigned u32 ID, without a version. GovernorPromotionAnalysis v2 retains promotion/Governor hashes, not live indices. Raw done-off-turn storage is preserved.
- GrandStrategic retains unsigned region IDs, signed CityPlanner v2 counters, RegionEvaluator v1, CitySettleSiteEvaluation v1, PlotEvaluation v5, VictoryStrategy v4, UnitProduction v1 and UnitEfficiencyInfo v4. Coordinates and Q8 values remain raw signed words. VictoryStrategy's named pseudo-yield priorities are actually serialized with **Yield** definitions; the transport preserves that native mismatch. The UnitEfficiency vector's inline capacity 64 is not a fixed saved count. Bool storage is retained as bytes, without gameplay truth semantics.
- Homeland stores raw unsigned control ID and a **signed additional-priority ordinal**. MoveList v1 separately counts signed base-move integers and Move v2 rows. Each Move saves an AllowedMove definition hash and signed priority. The legacy Move v1 ordinal grammar is refused. Each actual Homeland record is 604 bytes/72 items, with 36 base moves and 36 Move rows.

Every actual record checks exact byte/item roundtrip, exact prefix consumption, strict trailing refusal, exact and one-short byte/item budgets, a one-MiB unparsed suffix under the consumed-prefix byte cap, and two sequential records with a shared item allowance. There are **84,524 targeted native truncations** and **7,304 hostile native mutations**. Cuts cover scalar/count/version boundaries and one interior byte in first/last repeated elements, omitting middle repeated elements. This is not exhaustive native byte-prefix testing. Unknown versions and maximum counts are rejected under the actual byte limit and effectively unlimited item limits, exercising count preflight before allocation.

The small independent carriers populate nested forms and duplicate hash rows, signed/unsigned extremes, NUL/non-UTF8 strings and all four handler conditions. Additional root-empty vector carriers and every proper byte prefix of each small carrier are checked. One raw bool carrier in Diplomatic, Governors and GrandStrategic takes every value from 0 through 255; these are source cases, not claims that native fixtures or valid C++ boolean execution produce every byte. All bool storage observed in these native fixtures is zero or one. Existing module tests supplement these checks, including unequal Governor vectors and nested version failures. Empty native outputs, unsupplied branches and legacy-version acceptance are not inferred from the populated corpus.

All five decoders charge dynamic entries cumulatively, including byte strings, outer and inner vector entries and hash rows. Counts preflight checked minimum remaining wire, item capacity and addressable typed allocation size before fallible reservation. Absent handler arrays incur no count or item charge. Encoding measures the full byte/item traversal before fallible output reservation. These are aggregate wire/item caps and addressability checks, not an aggregate heap-byte cap or a native allocation/reconstruction oracle.

Native Read behavior remains distinct: live player lookup, definition remapping, default/unknown/duplicate hash treatment, archive ownership, callbacks and signals are not reproduced. Diplomatic handler initialization rebuilds evaluators; legacy state loading can call ChangeState; zero-length native strings can retain existing objects. Economic and Governors initialize native lists/services, GrandStrategic initializes regions and production, and Homeland restores control callbacks and subscribes signals. None of these records is blanket-excluded as planning-only, and all player decisions must still yield to external policies. Full Player live reconstruction, gameplay-affecting state and RNG, actions and turns remain unsupported. The recorded **89,198-byte raw Save→Load difference remains unclassified and unmasked**. This focused review does not independently accept the later combined prefix or Military codec.
