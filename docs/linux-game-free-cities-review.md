# Independent Linux FreeCities Manager wire review

No material defect was found in the reviewed bounded current-wire codec. This accepts Manager v3 and Instance v5 structural transport for the two complete observed records. It does not establish native Read reconstruction, definition remapping, NPC upkeep, gameplay state/RNG, actions or turns.

The immutable actual-export source is `194711e2f055328637563d2e5aa0eb52d4682651`. The [review driver](../evidence/linux/game-free-cities-review.py) extracts one unchanged Git archive, checks its existing `pub mod game_free_cities` export, runs the three actual module Cargo tests and strict all-target Core Clippy, builds the crate and links an external harness against its exported API. It hashes every archived file before and after the build. No export injection, source recovery or original-code execution occurs. [Recorded results](../evidence/linux/game-free-cities-review.json) bind source, archive, module, driver, harness and executable identities.

Original identities are Linux XP2 SHA-256 `a0b6611f45ed28fa7bf6e18d608cafddbdd5b1c20cfd880cb50937af731c1faa` and Linux host SHA-256 `106d4986567cf60aad787dfac990d089e41775e04b5f40e073f59a3a8ffe74f4`; host ET_EXEC VAs are absolute. The original audit's complete method fingerprints, concrete PLT call bindings and DWARF identity are reused after checking that driver against the immutable source. Independent disassembly review confirms Manager writer/reader `0x294d890`/`0x294d930` and Instance writer/reader `0x294b990`/`0x294ba50`.

Manager emits version 3, player ordinal, control-priority ordinal and its counted Instance vector. Instance emits version 5, player ordinal, city index, two signed coordinate words, raw living byte, turns-since-unit and urban-defense words, retaliation player ordinal, unsigned behavior-tree ID, and the two counted Unit/Building hash/bool arrays. Unit wrapper `0x294d020` and Building wrapper `0x294d060` resolve to concrete hash-array writers. Unit writer `0x294d310` explicitly emits collection count, each definition hash and the corresponding bool byte; Building uses the same concrete representation at `0x20031e0`. Signed ordinals/coordinates remain signed i32 words, hashes/IDs remain u32, and bool carriers retain all byte values. There are no strings, floats, Q8 fields or typed properties in this current grammar.

The independent Python parser is handwritten, rather than derived from the codec's record macro or the existing audit's generated schema. It projects every decoded scalar and vector length into ordered signed i64 carriers. A separately written Rust traversal projects every public decoded field using its concrete type. All 25,358 projected words per record must match before complete byte roundtrip is checked. It independently sums aggregate item charges and compares each Instance start/end against original native owner traces. All transitive descendants and all geometrically enclosed owner extents must equal those 55 Instance owners; trace emission order does not determine this comparison.

Both canonical stream contexts contain the same 64,366-byte record at `70963412..71027778`, following Barbarian.Manager and immediately preceding the 18-byte Random owner at `71027778..71027796`. Each record contains 55 Instances, 6,380 Unit pairs and 5,995 Building pairs, totaling 12,430 counted items. These two contexts supply one distinct FreeCities payload. Native traces select comparison records only; no offset or search is a production parser input. Definition-list lengths are read from saved bytes; no live rules registry is invented.

Validation rejects all 64,366 actual-record byte truncations per record, plus zero/u32::MAX changes at all 167 version/count words. Exact byte/item caps pass on decode and encode; one-short caps fail across aggregate nesting. Strict decode rejects an appended suffix, while prefix decode returns the exact record extent and item charge. A u32::MAX Instance count with unlimited caller caps fails on insufficient input before allocation. Source inspection confirms checked count/extent/allocation arithmetic, minimum input checks, shared item charging and fallible reservation. The allocation ledger checks overflow; it is not an independent heap-byte budget. Wire bytes and aggregate counted entries retain their separate `Limits` meanings.

The three unchanged-archive tests additionally exercise all 256 living/list bool bytes, every small-fixture cut, signed extremes, empty Manager, duplicate/unknown hashes, count attacks and historical version rejection. Native arrays are nonempty in the actual records; source-only empty containers and unusual bool/hash carriers remain transport fixtures. Accepting arbitrary hash order, duplicate hashes, unknown hashes or list lengths is a preservation contract, not proof that a particular live rules configuration would emit them. There is no typed-property fallback or opaque region in this codec.

Native Read resolves player pointers, initializes Manager signals, resets definition-indexed arrays and remaps hashes, consuming unknown hashes separately. Historical versions synthesize legacy defaults, whereas the transport rejects noncurrent versions explicitly. Those live effects remain outside acceptance. No NPC or AI-namespaced state is classified as planning-only. Exact rules/upkeep, gameplay-affecting NPC state and gameplay RNG remain in scope; future player decisions must yield to external policies.

The recorded raw Save→Load discrepancy remains **89,198 bytes**, unmasked and unclassified. Complete Player/world import, initialized-game acceptance, gameplay state/RNG, action execution and turn progression remain unsupported by this review.
