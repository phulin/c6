# Conditional Linux reporting-provider boundary

The corrected conditional SkipTurn profile records eleven balanced original reporting calls, but those entry/return observations do not establish callback effects. The first Rust Unit/Formation kernel must reject an unsupported reporting environment before mutation. Complete gameplay state, action execution and turns remain unimplemented; this audit does not change that scope.

The [static contract](../evidence/linux/reporting-provider-static.json) pins the supplied Linux XP2 `a0b6611f45ed28fa7bf6e18d608cafddbdd5b1c20cfd880cb50937af731c1faa` and host `106d4986567cf60aad787dfac990d089e41775e04b5f40e073f59a3a8ffe74f4`, method fingerprints and a four-hardware-breakpoint passive replay plan. Its parent is corrected configuration `b6ca58d53073abc2afa9176a4ceba350fafe3f91ba12dbf84fd08e25a3be9a5b`. Static checks execute no game code and do not count as an observed callback inventory.

The map sender `0x2d4a4b0` first reads enabled and suspended predicates. Its cache dispatcher synchronously calls each matching nonempty delegate; the original EngineUtility provider then updates dirty-component bookkeeping and dispatches a registered translator. Relevant host Publish methods query an optional synchronous pre-publish subscriber before creating a queued host event. A zero Send return or unchanged serialized bytes cannot establish that any of these surfaces are pure output. The [aftermath audit](linux-skip-turn-state-success.md#reporting-dispatch-boundary) retains the direct-call evidence.

The capture plan uses these checkpoints, with host addresses and game module RVAs retained separately:

| Checkpoint | Observation |
|---|---|
| Game `0x2d4a4c6` | Actual suspended result in AL, event/map, enabled byte `0x3c00649`, cache-update byte `0x3bffce8` |
| Game `0x2724777` | Resolved cache callback RAX and adjusted receiver RDI immediately before its tail jump; event/data/map and caller |
| Host `0x3214cb0` | Actual translator pointer after lookup/load, including null; event/data/map |
| Host `0x2fd7db0` | Actual DispatchData pre-publish pointer at `+0x10`, caller and raw delegate words |

Reporting suspension is not a guessed global bool: original IsSuspended tail-calls Globals::IsUnserializing, which combines WorldBuilder unserializing with the actual context's loading state. Capturing its return avoids fabricating those objects or calling original methods from the debugger. Reaching that checkpoint proves the earlier enabled predicate returned true; disabled sends miss it. The translator checkpoint only covers found registrations. A missing checkpoint must remain a coverage limitation until the full selected call sequence and relevant branches are reconciled.

The cache delegate checkpoint captures the target after original member-pointer adjustment and virtual resolution. For pre-publish registration inspection, the inspected original Linux member-delegate helpers read closure-this at `+0`, member pointer at `+8` and signed this-adjustment at `+16`; a low-bit-set member pointer resolves through the adjusted receiver's virtual table. Raw words, process addresses, mapped module identities and derived RVAs must all be retained. A nonnull registered pointer alone does not prove actual invocation or classify the target's effects. Any exercised target needs its own exact-target instruction/call evidence; namespace names do not establish cache-only or planning-only ownership.

The native lease owner runs the single same-source replay, using the archived preload and initialization profile with fresh output/userdata paths. No inferior calls, field writes, software game-code breakpoints or permanent hooks are part of this plan. Loader debugger instrumentation is reported separately. Hardware traps affect scheduling, so command bytes, original balanced execution, all Core stream identities, bounded typed state, worker quiescence and complete cleanup must be compared with the parent. Raw ASLR/live-object differences remain unmasked. Failed or incomplete replay results do not establish callback absence.

Until that inventory and target classification are complete, the kernel reporting contract remains unaccepted. It must bind actual flags, ordered invoked cache targets/receivers, translator identities, pre-publish registration/invocation and all affected state; unsupported inputs require rejection before mutation. Matching the known `be08f44a...` post-Core stream does not cover omitted live state, complete gameplay RNG, subscribers in other profiles or complete turns. Full-host admission and gameplay parity remain false. The separate raw Save→Load **89,198-byte failure** remains unclassified and unmasked.
