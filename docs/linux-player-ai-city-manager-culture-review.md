# Linux AI CityManager and Culture focused wire review

The current saved-wire codecs pass the focused independent review from actual-export source `50b849ac115ee82840b0ff55d25875e4a2755446`. This accepts bounded typed transport, not native Read restoration, AI policy, gameplay truth values or complete Player state. The [reproducer](../evidence/linux/player-ai-city-manager-culture-review.py) and [results](../evidence/linux/player-ai-city-manager-culture-review.json) use one unchanged Git archive; every archived regular file is hashed before and after actual Cargo tests, strict all-target c6-core Clippy and the release candidate build. No source or export injection is used.

For each stream, CityManager contains 245 CityBuilds, 9,065 PlotEvaluations and 11,547 UnitEfficiencyInfo records. Every UnitEfficiencyInfo start/end is compared with its native hook. Culture nested BoostManager, CivicAnalysis, PolicyAnalysis, ResolutionAnalysis and RockBandAnalysis extents are likewise compared individually, rather than only counting them. Their per-stream counts are 43, 2,623, 6,020, 817 and 50,434 respectively. These hooks select and validate offline fixtures; production parsing uses the typed grammar alone.

The review regates the complete native method manifests against target bytes **and exact ELF symbol sizes**, exact DWARF contracts, direct call/jump targets and concrete PLT bodies where resolvable. It additionally pins all 28 CultureAi archive load/save virtual slots and their complete bodies; 26 of these bodies extend the earlier 95-method manifest. CityManager has 130 complete method gates and 36 virtual slots; Culture has 121 complete method gates and 28 virtual slots. Unresolved import bodies are counted separately in the evidence; they do not become claims of reviewed concrete implementations.

CityManager's noncanonical bool storage is supported by the full writer/reader grammar and independent adjacent boundaries. The HasDistrict address is object `+0x51`, with writer call `0x1fd2dc9` and reader call `0x1fd2ef9`; EvaluateWonders is `+0x6c`, with calls `0x1fd2d5f` and `0x1fd2e93`. Each call's field-address instruction window and concrete bool overload are checked. The gated WriteObject/ReadObject bool bodies transfer one byte. Complete typed field projection, six signed-short neighbors, nested native efficiency extents and the actual following Culture hook all agree. Each stream contains 1,067 noncanonical HasDistrict bytes and 60 EvaluateWonders bytes, including twelve occurrences of byte 197. This is raw saved storage evidence. No logical interpretation such as nonzero-is-true is accepted.

The Python projections preserve every scalar, version, vector count, ordered entry and allocator word as signed or unsigned values as appropriate. The Rust projection selects all public CityManager fields mechanically and uses explicit Culture field accessors. The complete projected byte streams are compared directly, rather than relying on roundtrips or a semantic digest alone. CityManager covers v17 CityBuilds, recycled version 65537/block width 16, v4 efficiencies, v1 PlotEvaluation/reservations/handles/connections, v3 TradeCity, signed evaluation-layer counts, raw signed recycled slots and the uncounted free-index tail. Neither codec repairs a native allocator or remaps IDs. Culture covers v1 BoostManager and raw signed boost uniqueness carriers, v3 GreatWorks, v2 Civic/Resolution, v4 Policy and v1 RockBand records. Hashes and raw control IDs remain unsigned carriers; signed Q8 words and coordinates remain exact integers without numeric conversion. RockBand's PlotCoord has two signed words and no version; bool storage remains a byte.

All 172 actual records pass complete projection, exact byte/item roundtrip and prefix consumption, exact and one-short byte/item caps, strict trailing refusal and a one-MiB unparsed tail under the consumed-prefix byte limit. Native truncations cover selected container/count boundaries and each scalar boundary plus one interior byte in first/last repeated elements, omitting middle repeated elements. There are 68,472 precise native truncation cases; this is not exhaustive native byte-prefix testing. Hostile version/count mutations use an effectively unlimited item budget while preserving the actual byte limit, so count preflight must refuse before allocation.

Independent nonempty source carriers populate every nested vector form, including branches absent from the native fixtures, and preserve signed extremes, high-bit hashes, packed component halves and raw recycled metadata. One raw bool carrier in each codec takes every value 0 through 255. Every proper byte prefix of the two small nonempty carriers is rejected. Negative/high-bit signed layer counts, unsupported versions and malformed six-neighbor counts remain explicit failures. Five actual component Cargo tests supplement these new carriers; no proprietary fixture bytes are committed.

Both decoders charge all dynamic entries cumulatively and preflight minimum remaining wire, item capacity and addressable typed storage before fallible vector reservation. CityManager counts each recycled live/free entry, each evaluation layer and each of six neighbors; plain fixed PlotCoord/component words do not acquire item charges. Encoding measures the complete byte/item traversal before reserving output and writes within that reservation. These checks do not claim an aggregate heap-byte cap or native allocator restoration.

Native Read initialization, definition lookups, remapping, support-function rebuilding, archive callbacks and analyzer resets remain outside these transport codecs. In particular BoostManager Read appends managed boosts to existing live state, GreatWorks Read clears requests and resets its unsaved done flag, and Culture Read initializes/reset its live analyzers. No AI-namespaced data is excluded as planning-only. This review does not accept the later combined Player prefix or later AI components. All 43 complete Players, full gameplay state, gameplay RNG, actions and turns remain unfinished; the recorded 89,198-byte raw Save→Load difference remains unmasked.
